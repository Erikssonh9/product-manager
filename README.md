#Product Manager

En webbapplikation för produkthantering byggd med Node.js, Express, JavaScript och SQLite

#Funktioner

-Visa alla produkter.
-Lägg till nya produkter.
-Uppdatera produkter via API.
-Radera produkter.
-Spara produkter i en SQLite-databas.

#Tekniker

-HTML
-CSS
-JavaScript
-Node.js
-Express
-SQLite med better-sqlite3

#Installation

1.Klona projektet från GitHub
2.Öppna projektmappen i terminalen
3.Installera beroenden:
    npm install

#Databas


SQLite-databasen och tabellen skapas automatiskt när applikationen startas.
SQL-strukturen finns även i `database/schema.sql`.

#Starta applikationen

Kör följande kommande i terminalen:
    node server.js

Öppna sedan webbläsaren på:

http://localhost:3000
